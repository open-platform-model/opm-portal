The OPM portal serves a versioned read API, `/api/v1alpha1`, that its web UI and any other client read. [Portal read API](/docs/reference/portal/read-api/) lists its resources, the topics of its change stream and its problem codes. To start the portal, follow [Run the portal locally](/docs/operating/portal/run-the-portal-locally/); what it shows is explained in [The OPM portal](/docs/operating/portal/about-the-portal/).
